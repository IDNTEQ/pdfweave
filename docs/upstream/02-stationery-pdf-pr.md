## Title

`feat(common,generator): add StationeryPdf basePdf shape — PDF stationery on every reflowed page`

## Body

### What this adds

A new shape in the `BasePdf` zod union:

```ts
type StationeryPdf = {
  stationeryPdf: string | ArrayBuffer | Uint8Array;  // base64 / data URL / raw bytes
  width: number;          // mm
  height: number;         // mm
  padding: [number, number, number, number];
  staticSchema?: Schema[];  // optional, composes ON TOP of the stationery
};
```

Behaviour: the first page of `stationeryPdf` is stamped onto every output page generated by `generate()` — including pages added by table reflow. `staticSchema` (if provided) is drawn on top, so things like dynamic page numbers still work.

### Why

Today, `basePdf` is either:
- `BlankPdf` — supports `staticSchema` + table reflow + multi-page output.
- A custom PDF (string / ArrayBuffer) — supports a per-page background but **disables table reflow** (the generator embeds N pages from the source PDF and stops; `staticSchema` is ignored on these pages too).

The result: if you want a branded letterhead on every page of a multi-page invoice, you have to either:
1. Recreate the entire letterhead as `staticSchema` rectangles/text/lines (tedious; can't include real artwork from your design tool's PDF export); OR
2. Use a custom-PDF basePdf and lose table reflow (fail).

`StationeryPdf` fills the gap: import the artwork as a single-page PDF, declare the page geometry, and the generator stamps it on every reflowed page.

### What it doesn't change

- `BlankPdf` and the existing custom-PDF (`CustomPdf`) paths are unchanged.
- Public exports: nothing renamed. `StationeryPdf` type and `isStationeryPdf` helper are new exports from `@pdfme/common`.
- Bundle size: `@pdfme/common` +~600 bytes, `@pdfme/generator` +~1 KB.

### Implementation notes

1. **Detection ordering in `getEmbedPdfPages`** — `isBlankPdf` returns true for a `StationeryPdf` (zod ignores extra fields when both `width` and `height` and `padding` are present). The new branch checks `isStationeryPdf` BEFORE `isBlankPdf` so the correct path is taken. We did NOT change `isBlankPdf` semantics to preserve backwards compatibility.
2. **`treatsLikeBlank` helper** — used by reflow / `repeatHead` / `staticSchema` gates. Returns `true` for both `BlankPdf` and `StationeryPdf`. Lets the layout engine treat them uniformly while still letting consumers distinguish them via `isBlankPdf` / `isStationeryPdf`.
3. **One PDFEmbeddedPage per render** — the stationery is loaded once and embedded once via `pdfDoc.embedPages([firstPage])`, then `drawPage()`'d onto each fresh blank page sized to `width × height` (mm → pt via `mm2pt`). No per-page disk IO or re-parse.
4. **Page count** — `basePages.length === schemas.length`, so reflow is fully respected. The CustomPdf branch's behaviour (`basePages.length === embedPdfPages.length`) is unchanged.

// packages/generator/__tests__/stationery-pdf.test.ts
test('stationery PDF is stamped on every page including reflowed pages', async () => {
  const stationery = await fs.readFile('fixtures/letterhead.pdf');
  const template = {
    basePdf: { stationeryPdf: stationery, width: 210, height: 297, padding: [40, 20, 30, 20] },
    schemas: [[
      { name: 'items', type: 'table', position: { x: 20, y: 50 }, /* ... */ },
    ]],
  };
  // 80 line items → forces reflow to ~3 pages
  const inputs = [{ items: makeRows(80) }];
  const pdf = await generate({ template, inputs, plugins: { table } });
  const doc = await PDFDocument.load(pdf);
  expect(doc.getPageCount()).toBeGreaterThan(2);
  // Every page should reference the embedded stationery form-XObject.
  for (let i = 0; i < doc.getPageCount(); i++) {
    const page = doc.getPage(i);
    const refs = page.node.Resources()?.lookup(PDFName.of('XObject'), PDFDict);
    expect(refs).toBeDefined();
  }
});

### Migration guide

None — this is purely additive. Existing templates using `BlankPdf` or a custom PDF basePdf are unchanged.

✅ `BlankPdf` path unchanged.
✅ Custom-PDF (`CustomPdf`) path unchanged — same caps on page count and same restriction on `staticSchema` / table reflow.
