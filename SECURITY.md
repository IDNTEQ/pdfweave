# Security policy

## Supported versions

| Version | Supported |
|---------|-----------|
| Latest minor | Security fixes |
| Earlier | Best-effort |

## Reporting a vulnerability

Email **security@pdfweave.dev** or open a [GitHub Security Advisory](https://github.com/IDNTEQ/pdfweave/security/advisories/new). Please do not file public issues for vulnerabilities.

We aim to respond within 5 business days. Critical issues are patch-released within 14 days of confirmation.

## Scope

In scope:
- All `@pdfweave/*` packages on npm
- The `pdfweave.dev` website (limited; mostly static)

Out of scope:
- Vendored `@pdfweave/pdf-lib` issues that are upstream pdf-lib bugs (file at https://github.com/Hopding/pdf-lib)
- Issues affecting only the playground or website beyond what's published to npm

## Hall of fame

We thank contributors who responsibly disclose vulnerabilities. With your permission, we credit you here.
